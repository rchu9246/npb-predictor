# NPB(日本職棒)每日勝率預測系統

模型和 MLB / 中職版相同:**Log5(賽季勝率)+ 主場優勢 + 先發投手戰力 + 傷兵嚴重度**。
另外有預測核對、每日明細頁、累積準確率統計。

## 為什麼是「貼上文字」而不是自動抓?

NPB 官網不允許自動化程式存取,其他日文資料站也不是給程式抓的公開介面,所以這個版本**不爬任何網站**。
但 NPB 每天會公布兩段很精簡的文字,你貼進來就行,一天大約 30 秒:

| 什麼時候 | 貼什麼 | 貼到哪 |
|---|---|---|
| 賽前一天(官方公布予告先發後) | 「○/○(曜)の予告先発 （F-DB）孫易磊×東克樹 …」 | `data/matchups.txt` |
| 比賽打完後 | 「F 4-2 DB E 0-7 G L 5-4 C …」 | `data/actual_results/日期.txt` |

來源(用瀏覽器自己開、複製):
- 官網「予告先発投手」頁 https://npb.jp/announcement/starter/
- NPB 官方 X 帳號 @npb,每天有「○/○の予告先発」和「○/○の試合結果」兩則貼文,文字格式就是上面那樣,整段複製即可

## 快速開始

1. 先試範例(不會留下記錄):
   ```
   python npb_predictor.py --matchups data\examples\sample_matchups.txt --no-save
   ```
2. 正式使用:把官方的予告先發文字貼進 `data\matchups.txt`(檔案裡有 `//` 開頭的說明行,可以留著),雙擊 **`每日執行.bat`**,會自動跳出預測網頁。
3. 隔天比賽打完,貼比分:雙擊 **`新增比分.bat`**,輸入日期與比分(如 `F 4-2 DB E 0-7 G`);或直接建立 `data\actual_results\2026-09-29.txt`,把官方比分整段貼進去。
4. 再雙擊一次 `每日執行.bat`,核對報告和累積準確率就會更新。

Python 3.7 以上,不需要安裝任何套件。

## 格式說明

### 先發預告(matchups.txt)
- `（F-DB）孫易磊×東克樹`:**前面的球隊是主場**,`×` 前面是主場先發、後面是客場先發
- 日期要出現在文字裡(`6/11` 或 `2026-06-11` 都可以)
- 先發還沒公布就留空或寫「未定」,會以聯盟平均計算
- 官方貼文裡的網址、#NPB 標籤、球場名稱、開賽時間都會自動忽略

### 比分(actual_results/日期.txt)
- `F 4-2 DB`:主場球隊在前、比分主場在前(F 4 比 2 勝 DB)
- 和局照寫(`L 3-3 E`),會標示為和局、不計入命中率
- 雨天中止寫 `F 中止 DB`(需要直接編輯檔案,批次檔不支援中文)
- 檔名一定要是 `YYYY-MM-DD.txt`

### 球隊代碼
| 中央聯盟 | | 太平洋聯盟 | |
|---|---|---|---|
| G 巨人 | T 阪神 | H 軟銀 | F 日本火腿 |
| DB DeNA | C 廣島 | M 羅德 | E 樂天 |
| S 養樂多 | D 中日 | L 西武 | B 歐力士 |

## 順位表不用另外維護

`data/standings.json` 記的是「基準日」當天的戰績(目前是 2026-09-27,整理自 npbc.media,以 NPB 官網為準)。
基準日**之後**你貼進 `actual_results/` 的比分,系統會自動累加到戰績裡,預測某天時只會用到「那天之前」的比分。
所以只要有貼比分,順位表就是最新的。如果好幾天沒貼比分,戰績會停在舊的,預測會稍微失真。

## 投手戰力評分(建議做,但可以慢慢補)

沒填評分的投手一律以聯盟平均 6.0 分計算,網頁上會標示「預設」。**一開始大部分投手都是預設,
所以初期預測基本上只有球隊強弱和主場優勢在起作用**,這是正常的。

要讓先發投手發揮作用,在 `data/pitcher_ratings.json` 填入投手(名字照先發預告上的寫法,空白會自動忽略):
```json
{
  "東克樹": {"era": 2.10},
  "某某投手": {"fip": 3.20},
  "另一位": 7.5
}
```
防禦率可以到 NPB 官網「個人投手成績」查。換算:`戰力 = 6.0 − (防禦率 − 3.40) × 1.8`,限制在 1~10 分
(防禦率 2.10 ≈ 8.3 分、3.40 = 6.0 分、4.50 ≈ 4.0 分)。3.40 是我估的日職聯盟平均,可在程式最上方調整。

## 準確率怎麼看

網頁的「累積準確率」頁,或每天的核對明細(日期下拉選單可切換)。
- 單場棒球本身隨機性很高,專業模型單場命中率通常也只有 55~65%
- **樣本太少時數字沒有意義**:20 場的命中率,光是運氣就會有 ±10 個百分點的波動,建議累積 100 場以上再判斷
- 預測記錄一旦存下就不會被改寫:如果某天已經貼了比分,再貼同一天的先發預告時系統會拒絕覆蓋,避免用賽後資訊污染準確率

## 已知限制

- 主場優勢 53% 是憑印象設定的近似值,沒有用日職資料回測過
- 傷兵資料沒有公開量化來源,預設全部 60 分(不起作用),想用要自己調
- 季後賽(Climax Series、日本シリーズ)一樣可以貼、可以預測,但模型只看例行賽勝率,沒有考慮季後賽的特殊性
- 和局不計入勝率(採 NPB 官方算法);未來若中央聯盟採用指定打擊,模型不會特別處理
- 全部資料靠你貼,忘了貼就沒有預測、沒有核對

## 檔案

```
npb_predictor/
├── npb_predictor.py         主程式
├── 每日執行.bat               雙擊執行預測,自動開網頁
├── 新增比分.bat               雙擊輸入比分
├── 雲端版設定.md              (選用)放到 GitHub,用手機貼文字就自動更新網站
└── data/
    ├── matchups.txt           貼予告先發(每天)
    ├── actual_results/        貼比分(每天一個檔)
    ├── standings.json         順位表基準日戰績
    ├── pitcher_ratings.json   投手評分(選填)
    ├── injury_scores.json     傷兵分數(選填)
    ├── history/               預測記錄(自動產生,核對用)
    └── examples/              官方貼文格式範例
```
網頁輸出在 `site\` 資料夾:`index.html`(首頁)、`report.html`(預測)、`verify_report.html`(最近核對)、`stats.html`(累積)。
